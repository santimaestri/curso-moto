# Bloque 7 · Refrigeración líquida

*Clase 14 (repaso)*

El objetivo es que el motor llegue rápido a su temperatura de trabajo y se mantenga ahí. El termostato decide si el líquido pasa o no por el radiador; el electroventilador se prende y se apaga por ciclos.

## Qué se vio

- Circuito corto: motor → bomba → motor, sin pasar por el radiador, mientras el motor está frío.
- Termostato: entre motor y radiador; se abre con la temperatura y habilita el circuito largo (cilindro → radiador → bomba). No corta del todo el flujo. Antes se lo sacaban a los autos cuando fallaba, y eso trae problemas: el agua pasa siempre al radiador.
- El circuito es hermético y presurizado: por eso el líquido no hierve a 100 °C. Depósito de expansión para que no se pierda refrigerante.
- Riesgos: juntas dañadas que mezclan aceite y refrigerante; abrir la tapa del radiador en caliente.

## Datos que hay que saber

| Evento | Temperatura (la mayoría de los modelos) |
| --- | --- |
| Se prende el electroventilador | 98 °C |
| Se apaga el electroventilador | 90–92 °C |
| Ebullición del agua a presión atmosférica | 100 °C |

## Preguntas para chequearte

1. ¿Qué diferencia hay entre el circuito corto y el largo? ¿Quién decide cuál se usa?
2. ¿Qué pasa si se saca el termostato?
3. ¿Por qué el líquido no hierve aunque pase los 100 °C?
4. ¿A qué temperatura se prende y se apaga el electroventilador, y por qué va en ciclos?
5. ¿Por qué no se abre la tapa del radiador con el motor caliente?
